# Contribute to the documentation

The documentation for this plugin is powered by MkDocs and the Material theme.

## How to Edit

1. **Locate the File**: All documentation files are located in the `docs/` directory.
2. **Markdown Format**: We use standard Markdown with some additional extensions (like admonitions for notes and warnings).
3. **Preview Changes**: You can preview the documentation locally by running:
   ```bash
   mkdocs serve
   ```
   Then open `http://127.0.0.1:8000` in your browser.

## Documentation Structure

- `index.md`: The landing page.
- `tutorial/`: Step-by-step onboarding.
- `how_to/`: Practical guides for specific tasks.
- `explanation/`: Architectural and conceptual guides.
- `reference/`: Technical specifications.

Please ensure that any new features added to the code are also reflected in the documentation.
